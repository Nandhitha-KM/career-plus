Slide 08 • Technical Successes

Engineering Challenges & Resolved Issues

1. Deduplicated CORS Preflight Filter

Configured `@Order(Ordered.HIGHEST_PRECEDENCE)` `CorsWebFilter` in API Gateway to approve all preflight `OPTIONS` requests instantly with `200 OK`.

2. Flexible JSON Deserializer & String IDs

Added custom `@JsonSetter("id")` in `Application.java` catching client string IDs (`job-1787727786433`) and stripping them so SQLite auto-generates numeric IDs without 400 Bad Request errors.

3. Regex Path Mapping Protection

Configured `@GetMapping("/{id:[0-9]+}")` to prevent wildcard `{id}` matching against `/actions/today` and `/analytics/insights` routes.
